# Mixed-licence media in an open repository

Bundling CC BY / CC BY-SA media inside an MIT-licensed code repository is
standard and lawful when the media keep their own licence and attribution
(code MIT, assets CC BY-SA, recorded in a licence inventory such as a
REUSE/SPDX `REUSE.toml` or an assets-licence file); share-alike then
attaches to the media only. NC-licensed material can never be bundled in a
repository intended for commercial reuse — see
<ctxmod_link path="ctx:github.com/ctxmod/design/context::shared::sign_language_media@public_sector_web/reference/sts_media_licensing.md" />
for the worked case.
