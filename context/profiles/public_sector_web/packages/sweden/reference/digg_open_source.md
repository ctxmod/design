# Open source: DIGG's publication checklist

DIGG's "Policy och riktlinjer för anskaffning, utveckling och publicering
av öppen programvara" (2026-06-03) and its handbook publication checklist
describe what a Swedish authority expects of published source code.
Verified 2026-10-30. A repository can adopt the checklist as checkable
compliance artefacts:

- LICENSE file with an OSI-approved licence, REUSE/SPDX headers
- `publiccode.yml`
- Issue and PR templates, CODEOWNERS
- DCO `Signed-off-by` or a CLA
- Public issue tracker, a vulnerability-reporting route (SECURITY)
- README stating what it does, for whom and how to run it, plus an
  architecture description, maturity status and support window — all
  public already under development
- DIGG provides a template project (`diggsweden.github.io/opensource-docs`)
- IT-strategin wording to match: license agency-owned source "som öppen
  källkod om det inte finns skäl att göra undantag", under "så tillåtande
  licens som möjligt"
