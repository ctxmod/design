# Swedish public design systems

Verified 2026-10-30.

- **FKUI** (`github.com/Forsakringskassan/designsystem`, MIT): Vue 3,
  Lerna + npm workspaces, weekly releases, WCAG 2.2 AA target. Opened to
  other agencies in 2024-10, and other agencies' portals build on it.
- **Digi** (`@designsystem-se/af`, Arbetsförmedlingen): web components and
  Angular, Apache-2.0, on GitLab, with Figma assets, used by several
  agencies.
- Both are listed on offentligkod.se, the national open-source register.
